# Veda Construction Ltd

Static website recreated from the supplied Emergent preview screenshots.

## GitHub Pages
1. Create a public GitHub repository named `veda-construction`.
2. Upload all files and the `images` folder.
3. Open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.
